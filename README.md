# 🎵 Maes — Site Discographie

> Projet réalisé dans le cadre de la formation **La Toile** — *EM Lyon Business School*

---

## 📋 Présentation

Site web dédié à la discographie du rappeur français **Maes**, conçu avec une esthétique **glassmorphisme** et une attention particulière portée à la **lisibilité du texte**.

Le projet explore les fondamentaux du développement web front-end (HTML, CSS, JavaScript) à travers un cas concret et créatif.

---

## 🎯 Objectifs pédagogiques

- Structurer un projet web multi-pages en HTML sémantique
- Maîtriser les effets **glassmorphisme** (`backdrop-filter`, `rgba`, `blur`)
- Garantir une **lisibilité optimale** malgré les fonds transparents
- Intégrer des composants interactifs en JavaScript vanilla
- Créer une expérience responsive et accessible

---

## 📄 Pages du site

| Page | Fichier | Description |
|---|---|---|
| **Accueil** | `index.html` | Présentation de l'artiste, biographie, stats, timeline discographique |
| **Albums** | `album.html` | Grille des 5 albums avec pochettes, popularité et liens Spotify |
| **Tracklist** | `tracklist.html` | Détail des titres par album via un système d'onglets interactifs |
